# Spec Delta

## Purpose

本能力为终端对话提供可预测的运行时配置入口，并让默认本地会话与调用记录跟随所选配置目录。用户可以在本项目运行时使用项目配置，把配置放在程序旁边随程序移动，或统一放在个人目录；从不同工作目录启动时，配置和默认数据位置仍保持一致。

## ADDED Requirements

### Requirement: 运行时配置文件位置

系统 MUST 优先使用可执行文件同级目录中的 `.env`；本项目的普通 Cargo 构建产物在同级没有文件时，MUST 使用项目根目录的 `.env`；其余情况 MUST 尝试用户主目录下的 `.geer-agent/.env`。内嵌配置构建 MUST 不把构建时的项目文件当作运行时外部文件。系统 MUST 不因启动工作目录或其父目录中的 `.env` 改变选择。进程环境变量 MUST 优先于选定文件，选定文件 MUST 优先于可选的内嵌配置；选定文件存在但读取或解析失败时，系统 MUST 显示错误，而非改用另一文件。

#### Scenario: 程序旁边有配置

- **WHEN** 可执行文件同级和用户配置目录均有 `.env`，并从第三个目录启动程序
- **THEN** 程序读取可执行文件同级的文件，且不读取用户配置目录或启动目录中的文件

#### Scenario: 回退用户配置

- **WHEN** 可执行文件同级没有 `.env`，用户配置目录有 `.env`
- **THEN** 程序读取用户配置目录的文件

#### Scenario: cargo run 使用项目配置

- **WHEN** 用户通过普通 `cargo run` 从本项目启动、构建产物同级没有 `.env`、项目根目录有 `.env`
- **THEN** 程序使用项目根目录的文件，并以项目根目录作为默认本地数据目录

#### Scenario: 只有进程或内嵌配置

- **WHEN** 可用的运行时位置均无外部 `.env`，但进程环境或可选内嵌配置提供了必需值
- **THEN** 程序可启动，并把用户配置目录作为默认本地数据目录的依据

#### Scenario: 文件错误不隐式回退

- **WHEN** 可执行文件同级的 `.env` 存在但无法读取或解析
- **THEN** 程序显示配置错误，不改读用户配置目录的 `.env`

### Requirement: 默认本地数据库与配置同目录

使用默认 SQLite 数据库时，系统 MUST 将会话和调用记录写在最终选定配置目录的 `.db/geer.sqlite`，并在需要写入时创建 `.db/`。显式指定数据库地址时，系统 MUST 继续使用该地址。

#### Scenario: 程序旁边的默认数据库

- **WHEN** 程序使用可执行文件同级的 `.env` 且未显式指定数据库地址
- **THEN** 默认数据库位于该 `.env` 同级的 `.db/` 中，与启动工作目录无关

#### Scenario: 用户目录的默认数据库

- **WHEN** 程序使用用户配置目录的 `.env`，或所有候选位置都没有外部 `.env` 而仅使用进程或内嵌配置
- **THEN** 默认数据库位于用户配置目录的 `.db/` 中

#### Scenario: 显式数据库地址

- **WHEN** 用户显式设置数据库地址
- **THEN** 会话和调用记录继续使用该地址，不重写为默认本地路径
