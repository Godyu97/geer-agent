# Proposal

## Why

仓库目前只有启动占位输出，尚不能与模型进行持续对话。实现教程 Day 1 的 REPL 地基后，用户可以在终端进行流式多轮聊天，为后续工具循环提供可运行的基础。

## What Changes

- 用户启动程序后可以输入问题，并在模型生成时逐段看到回答。
- 每轮请求携带当前会话历史；用户可用 `/reset` 清空历史，用 `/help` 查看命令，用 `/exit` 结束对话。
- 用户通过本地 `.env` 或环境变量提供模型配置；缺少必需配置或请求失败时，会看到明确错误。
- 终端遇到无效 UTF-8 输入时提示重试，流式请求长时间没有可显示回复或返回空回复时提示失败，并允许继续对话。
- 交互终端用颜色区分输入与模型输出，提示标签显示为“李火旺🔥”和“Ai”。

## Capabilities

### New Capabilities

- `repl-chat`：提供可持续交互、保留当前会话历史并流式显示模型回答的终端聊天能力。

### Modified Capabilities

无。

## Non-goals

- 不实现工具调用、文件操作、会话持久化或 TUI。
- 不引入通用 provider 抽象或其他模型服务商。

## Impact

- Rust 二进制入口与新增的配置、聊天和 REPL 模块。
- 增加 OpenAI Chat Completions SDK、异步运行时、流迭代和 `.env` 加载依赖。
- 增加 `.env.example`，并忽略本地 `.env`，避免误提交密钥。
