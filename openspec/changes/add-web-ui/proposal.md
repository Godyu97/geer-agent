# Proposal

## Why

现有桌面界面只能在本机窗口使用，React 页面直接依赖 Tauri。增加局域网浏览器入口，并让桌面与浏览器复用同一套交互和视觉，避免会话功能开发两次。

## What Changes

- 增加独立 Web 模式，监听全部 IPv4 网卡，默认 8827，端口通过环境配置。
- 提供临时或固定访问口令，支持同一用户多个浏览器同步查看和串行操作同一个 Agent。
- Web 覆盖现有桌面聊天、历史、工具授权、会话管理、workspace、压缩与用量，支持手机布局。
- 任一已登录端可回答工具授权；页面退出保存并只断开本端，终端信号停止服务。
- GUI/Web 共用前端与会话桥接；前端依赖、锁文件及脚本入口统一使用 Bun。

## Capabilities

### New Capabilities

- `web-ui`：浏览器接入、认证、多端同步、会话交互与服务生命周期。

### Modified Capabilities

无。已有 GUI、会话持久化和工具循环契约继续适用。

## Impact

涉及 UI 分派与配置、图形会话桥接、展示历史编译开关、共用 React 前端、构建命令与架构文档；增加可选 HTTP/WebSocket 与静态资源嵌入依赖。现有终端默认选择、模型协议及数据库格式保持兼容。

## Non-goals

不增加账号、多用户隔离、云端部署、GUI/Web 同进程并行运行或另一套会话存储；不更换现有 Vite、TypeScript 和 Vitest 工具。
