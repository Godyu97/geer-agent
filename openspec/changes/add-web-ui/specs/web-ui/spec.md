## Purpose

浏览器界面让仓库所有者在本机和局域网设备使用已有 Agent 能力，通过访问口令保护会话和工具入口，在多个浏览器之间同步当前会话、实时回答与授权状态，并以与桌面一致的界面完成聊天和会话管理。

## ADDED Requirements

### Requirement: 可选浏览器入口

系统 MUST 提供独立浏览器模式，监听 0.0.0.0，默认端口 9928，并允许通过 GEER_AGENT_WEB_PORT 设置 1 到 65535 的端口。未包含浏览器能力、端口非法、端口占用或缺少必需模型配置时 MUST 明确失败；默认终端和桌面选择 MUST 保持兼容。

#### Scenario: 默认和自定义端口
- **WHEN** 用户启动浏览器模式，未设置端口或设置有效端口
- **THEN** 服务在默认或配置的端口提供页面，并显示访问地址

#### Scenario: 配置或监听失败
- **WHEN** 端口非法、已被占用或缺少模型必需配置
- **THEN** 程序明确报错退出，不静默换端口或假成功

### Requirement: 访问口令

系统 MUST 在未设置 GEER_AGENT_WEB_TOKEN 或其为空时生成并显示一次临时口令；设置后 MUST 使用固定口令。未登录请求 MUST 不能读取会话或调用工具。浏览器凭证 MUST 在服务重启后失效，跨来源写请求 MUST 被拒绝。口令和模型密钥 MUST 不进入页面资源、地址参数、会话内容或业务事件。

#### Scenario: 多设备登录
- **WHEN** 两个设备使用同一有效口令登录
- **THEN** 两端均能进入同一个服务，错误口令不能访问会话

#### Scenario: 重启与跨来源
- **WHEN** 旧凭证用于重启后的服务，或其他来源发起操作
- **THEN** 请求被拒绝并要求重新登录或显示来源错误

### Requirement: 共用会话交互与多端同步

浏览器界面 MUST 提供流式聊天、完整历史、会话新建和打开、workspace、压缩、保存、用量及会话管理。多个浏览器 MUST 共用当前会话和 workspace，操作串行，忙碌或状态过期的提交 MUST 明确拒绝。连接和重连 MUST 获取当前完整展示状态，包括正在运行的回答，并且 MUST 不自动重发未确认命令。

#### Scenario: 运行中加入
- **WHEN** 一端正在接收回答，另一端连接或刷新
- **THEN** 新端立即看到历史、当前输入、已生成文本和后续增量

#### Scenario: 竞争和过期提交
- **WHEN** 两端同时提交，或一端尚未看到另一端的会话切换就提交
- **THEN** 只有一项操作执行，忙碌或过期的请求明确失败且不会投到错误会话

#### Scenario: 各端草稿与删除
- **WHEN** 另一端切换会话或删除当前会话
- **THEN** 草稿按会话标识在本端保留，已删除当前会话的草稿被清除；删除预览只在发起端显示且状态变化使旧确认失效

### Requirement: 多端工具授权

待授权操作 MUST 向所有已登录端展示，第一份有效回复 MUST 生效并同步解除弹窗，迟到回复 MUST 被拒绝。全部连接断开或等待 120 秒 MUST 默认拒绝；连接恢复 MUST 不恢复已过期的授权。

#### Scenario: 另一端回答授权
- **WHEN** 电脑发起工具操作，手机先回复授权，电脑随后回复
- **THEN** 手机回复生效，电脑弹窗解除，其迟到回复不授权下一项工具

#### Scenario: 失联或无人回答
- **WHEN** 所有页面断开或授权等待超过上限
- **THEN** 工具不因缺少回答被允许，服务可以继续处理后续输入

### Requirement: 页面与服务退出

输入 /exit MUST 先保存再只退出当前页面；保存失败 MUST 提供重试、返回或明确断开。关闭标签页 MUST 不停止共享服务。终端停止信号 MUST 停止接收新操作、解除授权、等待当前操作收尾并保存；保存失败 MUST 明确报告且以失败状态退出。

#### Scenario: 一端退出
- **WHEN** 一端输入 /exit 并成功保存
- **THEN** 该页面断开，其他页面仍可使用服务

#### Scenario: 保存失败
- **WHEN** 页面退出时存在待保存或仅内存会话
- **THEN** 页面显示真实保存状态，用户可以返回或明确断开

### Requirement: 桌面与手机可用性及连接额度

浏览器界面 MUST 沿用桌面视觉，在 375 像素宽度仍可聊天、查看会话和状态及回答授权。workspace MUST 使用服务端路径；无法自动复制代码时 MUST 提供手动复制。服务 MUST 限制为 16 个连接及每端 256 项待发送事件，慢端 MUST 断开并可重新同步。输入 MUST 不超过 65536 字节，入站消息 MUST 不超过 512 KiB；连接 MUST 每 15 秒探测并在 45 秒无响应后断开。

#### Scenario: 手机和局域网访问
- **WHEN** 用户在手机通过局域网 HTTP 访问
- **THEN** 会话及状态可通过折叠面板查看，授权可操作，复制不可用时能手动选择文本

#### Scenario: 慢端和连接上限
- **WHEN** 某端积压超过额度或连接已满
- **THEN** 服务明确拒绝或断开该端，其他端和 Agent 继续工作
