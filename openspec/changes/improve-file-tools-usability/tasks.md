## 手工效果抽样步骤

使用隔离的临时目录准备一个嵌套文本文件、一个含重复片段和可检索标记的文本文件，以及一个超过 2000 行的 UTF-8 文件。确认所配置 Bash 环境能找到 `ls/rg`，在用户已配置的接口下运行 `cargo run`，按现有流程逐工具授权；以下输入均明确限制目标为该临时目录。

1. “查看这个目录，并找出所有文本文件，再读其中一个文件前 20 行。”观察模型是否直接使用 `ls/glob/read`，并正确结合结果中的根目录解释路径。
2. “继续读取刚才没有返回的部分。”观察模型是否复用工具给出的 `next_offset`，而不是把它当作字节或从头重复读取。
3. “只修改这段文字，保持其他内容不变，再确认结果。”观察模型是否选择 `edit`，从正文复制锚点，不把元信息写入文件。
4. 对含重复片段的文件，使用离线用例确定的歧义调用检查恢复提示，再让模型按提示扩大上下文完成修改；记录是否重复同样的无效参数。
5. “将已经相同的完整内容再写入一次。”确认结果明确未改变，且修改指标不增加。
6. “找出内容匹配这个正则的文本文件，只列路径；然后显示一个文件的命中行并读取上下文。”观察模型是否使用 `rg`，正确区分正文 `pattern` 与路径 `glob`，根据需求切换 `files/content`，再用 `read` 获取原文。

效果记录只保留工具序列、成功/错误类型、是否恢复及结果大小；不提交配置、密钥、完整对话或用户文件内容。以上抽样不能替代两种协议的离线回归，也不构成统计上的准确率评估。
