# Spec Delta

## ADDED Requirements

### Requirement: 明确且一致的文件工具调用契约

系统 MUST 向两种已支持的模型接口提供语义一致的文件工具定义，说明每个工具的用途、选择边界、参数含义、单位、默认值、限制及简短调用示例。系统 MUST 为目录浏览、路径通配查找和正文正则搜索提供三个独立入口，并说明其与正文读取、完整写入和局部编辑的区别；所有文件工具 MUST 在授权和操作之前拒绝未知参数、错误类型及无效必填值，嵌套编辑项遵循同样规则。模式语法的执行错误 MUST 作为可读结果返回。

#### Scenario: 模型选择局部编辑

- **WHEN** 模型读取工具定义以决定如何修改现有文本的一小段
- **THEN** 定义说明使用 `edit`，从已读正文复制足够上下文作为 `oldText`，保留空白和缩进，且同一批编辑均以修改前的内容为基准

#### Scenario: 两种接口获得相同语义

- **WHEN** 用户分别使用两种已支持的模型接口开启工具
- **THEN** 两种接口均声明相同的六个文件工具及参数说明，原有 `read/write/edit` 名称和合法参数继续可用

#### Scenario: 参数不符合声明

- **WHEN** 调用包含未知参数、非整数的行偏移、空白路径或空的旧文本
- **THEN** 系统返回指出参数位置和有效取值的错误，不询问授权，也不执行文件操作

### Requirement: 有界目录浏览

系统 MUST 提供 `ls`，接受可选目录路径，默认使用启动目录，列出直接子项并包含隐藏项；输出 MUST 显示目标目录，保留底层命令的列表表示，目录标记和名称顺序由声明的命令选项决定。系统 MUST 对完整工具结果应用统一的命令输出限制，并在截断时建议缩小目标目录或按路径模式查找，不提供无法保证正确的条目总数或分页偏移。

#### Scenario: 查看大型目录

- **WHEN** 请求的目录列表超过命令输出限制
- **THEN** 系统返回有界的列表、截断标记和缩小查询范围的建议，不把结果描述为完整列表

#### Scenario: 空目录或无效目录

- **WHEN** 模型查看空目录、不存在的目录，或将普通文件作为目录路径
- **THEN** 空目录返回成功且列表为空，其余无效路径返回原因及修正建议，不伪装为空目录

### Requirement: 有界文件路径查找

系统 MUST 提供 `glob`，接受必填路径模式和可选搜索目录，默认从启动目录搜索；完整结果 MUST 遵守统一的命令输出限制。路径模式 MUST 相对搜索目录解释，支持底层查找命令的通配语法，不得解释为正文正则。系统 MUST 标明搜索根和返回路径的相对基准，并采用底层命令的忽略规则、通配过滤和符号链接策略；定义 MUST 说明显式路径过滤对默认忽略规则的影响，不承诺额外的自定义遍历语义。结果不完整时 MUST 标记截断并建议缩小目录或模式，不得报告未经完整统计的总匹配数。

#### Scenario: 根据路径模式定位源码

- **WHEN** 模型指定某搜索目录和跨层级路径模式
- **THEN** 系统返回符合底层过滤规则的文件路径，不返回正文，并明确返回路径相对哪个搜索根解释

#### Scenario: 无匹配与过多匹配

- **WHEN** 搜索没有匹配，或结果超出命令输出限制
- **THEN** 前者返回成功、数量为零且未截断；后者返回有界结果、截断状态和收窄搜索的提示

#### Scenario: 搜索不完整或模式无效

- **WHEN** 路径模式无效、搜索根无法访问，或底层命令报告无法完成搜索
- **THEN** 系统返回明确错误和调整模式、搜索根或访问权限的建议，不将未完成的搜索描述为完整结果

### Requirement: 有界正文正则搜索

系统 MUST 提供独立的 `rg` 工具，接受必填正文匹配模式、可选文件或目录路径、可选路径通配过滤及输出方式，默认搜索启动目录、按正则匹配并返回匹配行。系统 MUST 支持 `content` 和 `files` 两种输出方式：前者提供命中文件、从 1 开始的行号和匹配文本，后者仅返回去重后的命中文件路径；`files` 仍以正文匹配决定命中，不将正文正则用于匹配文件名。系统 MUST 支持按字面文本搜索的显式选项，说明底层正则引擎的限制，并使返回路径的解释基准可见。

#### Scenario: 正则定位代码并读取上下文

- **WHEN** 模型提供正文正则和可选的源码路径通配过滤
- **THEN** 系统返回包含路径、行号及匹配文本的有界结果，模型可以据此使用读取工具获取完整上下文

#### Scenario: 仅查找含指定内容的文件

- **WHEN** 模型选择 `files` 输出方式
- **THEN** 系统只返回正文命中的文件路径，不重复输出同一文件，不输出匹配正文

#### Scenario: 字面文本或非法正则

- **WHEN** 模型选择按字面文本匹配，或提交底层引擎不支持的正则
- **THEN** 字面文本中的正则元字符按普通字符搜索；非法正则返回失败原因和调整模式的建议，不伪装为零匹配

### Requirement: 命令查询结果与失败语义

目录浏览、路径查找和正文搜索 MUST 返回命令退出状态、截断状态和必要的错误说明，完整工具结果 MUST 不超过 2000 字符，命令执行超时 MUST 终止并明确失败。系统 MUST 将正常无匹配与命令缺失、权限错误、语法错误和超时区分；缺少依赖时 MUST 仅使对应工具失败，不阻断原有聊天和文件读写。路径和模式参数 MUST 作为参数值处理，不能因空格、引号、命令替换符号或前导短横线而被执行为额外命令或解析成选项。

#### Scenario: 无匹配与缺少命令

- **WHEN** 搜索命令正常完成且没有匹配，或运行环境缺少该命令
- **THEN** 前者成功返回无匹配，后者返回依赖不可用及处理建议，不把两者混为同一结果

#### Scenario: 特殊参数与截断

- **WHEN** 路径或模式含有 Shell 特殊字符，或命令输出超过限制
- **THEN** 参数保持字面传递，不执行额外操作；超限结果明确标注不完整，并保留可理解的下一步建议

### Requirement: 可恢复的文件操作反馈

文件工具失败时 MUST 返回稳定的错误类别、可用的路径或参数位置、简短原因和具体下一步建议。匹配失败 MUST 区分旧文本缺失、存在歧义和编辑区间冲突，并明确校验失败未修改文件；错误结果 MUST 不回显整份文件或无界的旧文本。成功结果 MUST 将操作元信息与正文或路径列表明确分开；同一输入、文件状态和命令环境的结果 MUST 不额外包含工具自身生成的时间戳或耗时。

#### Scenario: 旧文本不存在

- **WHEN** 一次编辑中的某段旧文本未在当前文件找到
- **THEN** 结果指出该编辑项，说明文件未修改，并建议重新读取目标区域后复制精确旧文本，不建议盲目重复相同调用

#### Scenario: 旧文本存在歧义

- **WHEN** 一段旧文本在多个位置匹配
- **THEN** 结果说明至少存在两处匹配，建议增加前后文；如给出位置提示，提示数量保持有界

### Requirement: 如实报告文件变更

系统 MUST 在写入和编辑的成功结果中说明目标路径及内容是否实际改变。已有文件与请求内容相同，或有效编辑的最终内容与原内容相同时，系统 MUST 成功返回“未改变”、不重复写盘，也不将其计作有效文件修改；创建原本不存在的空文件 MUST 计作实际改变。

#### Scenario: 重复相同修改

- **WHEN** 已有文件的完整写入内容相同，或旧文本有效但替换后整体内容相同
- **THEN** 操作成功、文件内容不变，修改计数不增长，重复无效修改不能通过声称文件改变来重置循环保护

## MODIFIED Requirements

### Requirement: 文本读取

系统 MUST 接受路径及可选的起始行和行数，读取 UTF-8 文本；起始行从 1 计数，默认起始行 1、最多 2000 行，显式请求超过 2000 行时仍按 2000 行截取。单次完整结果 MUST 限制在 2000 行正文和 50 KiB 内，并附带目标路径、实际行范围和截断状态；未读完时 MUST 给出准确、可直接复用的下一起始行。正文 MUST 保持原有文本，不插入行号、缩进或省略号，不切断 UTF-8 字符或完整行。无法读取或参数无效时 MUST 返回明确错误，不为获取总行数而要求额外扫描整个文件。

#### Scenario: 分段读取

- **WHEN** 模型按路径读取超过单次限制的文本文件
- **THEN** 系统返回当前完整行片段、实际行范围和下一起始行，继续读取可以得到紧接着的内容

#### Scenario: 非文本或无效范围

- **WHEN** 请求片段不是有效 UTF-8 文本，或起始行超出文件范围
- **THEN** 系统返回原因和修正建议，不把无效内容交给模型，也不返回无法前进的续读参数

#### Scenario: 空文件与超长单行

- **WHEN** 请求空文件的第一行，或请求的首行无法放入单次结果字节上限
- **THEN** 空文件返回零行、无正文且未截断；超长单行返回明确错误，并建议使用命令工具进行针对性的分段读取

### Requirement: 创建与覆盖

系统 MUST 接受路径和完整文本内容，在授权后创建缺失的父目录和文件，或覆盖已有文件；定义 MUST 明确这是整体写入，局部修改优先使用精确编辑。结果 MUST 说明实际是否改变，失败时 MUST 返回原因与下一步建议，不把无法读取已有文件的情况当作文件不存在。

#### Scenario: 创建新文件

- **WHEN** 模型提供新文件路径和内容，且用户已授权 `write`
- **THEN** 系统创建文件及所需父目录，返回完成结果并标记实际改变

#### Scenario: 无法检查已有内容

- **WHEN** 目标已存在但无法读取以确认已有内容
- **THEN** 系统返回访问错误，不将目标视为空文件继续覆盖

### Requirement: 精确编辑

系统 MUST 接受文件路径和一组旧文本/新文本替换；每段非空旧文本 MUST 在修改前的原文件中唯一匹配，唯一性 MUST 包括相互重叠的匹配，各替换区间 MUST 互不重叠。所有编辑 MUST 在同一份原内容上完成校验，不将前一项新文本作为后一项旧文本的匹配来源。任一匹配无效时 MUST 保持文件不变并返回原因及修正建议；全部有效时 MUST 一次生成最终内容，并依据实际差异决定是否写入。

#### Scenario: 多处互不重叠的编辑

- **WHEN** 所有旧文本在原文件中各匹配一次且互不重叠
- **THEN** 系统应用所有替换并报告是否改变，正常编辑继续保留已有文本标记和统一换行格式

#### Scenario: 缺失、重复或重叠匹配

- **WHEN** 任一旧文本缺失、出现多次或与另一替换区间重叠
- **THEN** 系统拒绝整次编辑，文件内容保持原样，并给出重新读取、扩大旧文本上下文或合并冲突编辑的对应建议

#### Scenario: 旧文本自身发生重叠重复

- **WHEN** 原内容为 `aaa`，模型请求将旧文本 `aa` 替换为其他文本
- **THEN** 系统识别出两个起点不同的匹配，拒绝有歧义的编辑，保持文件原样

### Requirement: 文件工具授权与路径

系统 MUST 对 `ls`、`glob`、`rg`、`read`、`write`、`edit` 分别在本次会话首次使用时展示目标路径并取得明确授权；授权后允许使用相对启动目录的路径或本机绝对路径，并保留家目录简写行为。拒绝或 `/reset` 后 MUST 不沿用授权。关闭工具时 MUST 不声明或执行任何文件工具；只读调用的并行执行 MUST 先完成逐项授权，按原调用顺序回传结果，且不得跨越写入、编辑或通用 Bash 操作。固定只读查询的授权 MUST 不授予执行任意命令的权限。

#### Scenario: 首次授权与重置

- **WHEN** 用户首次允许某文件工具，随后再次使用，再输入 `/reset` 后再次使用
- **THEN** 第二次调用复用授权，重置后的调用重新询问，其他文件工具不继承该授权

#### Scenario: 只读工具与写入混合

- **WHEN** 同一批调用包含目录浏览、路径查找、正文搜索、读取、写入和再次读取
- **THEN** 授权后的连续只读调用可并行，结果按请求次序回传；写入完成后才开始后续读取

#### Scenario: 拒绝授权或关闭工具

- **WHEN** 用户拒绝文件工具授权，或在启动时关闭全部工具
- **THEN** 被拒绝或关闭的操作不执行，拒绝时明确报告未执行且不保存授权，关闭时模型请求不携带工具定义
