# Design

## Context

动机见 proposal。现有工具批次已显式接收会话 workspace；原生文件读取与只读命令共享路径解析。主要缺口在界面瞬态清理、SQL 原子性和磁盘恢复的附加状态。

## Goals / Non-Goals

**Goals:** 在已有模块中补齐边界，沿用两种模型协议、事件重试和会话乐观锁，新增可复现回归。

**Non-Goals:** 不增加依赖、数据库列或环境变量，不扩大工具权限，不自动继续中断轮次。

## Decisions

1. **终端增量与清屏。** 流式估算仅为新增字符除以二向上取整；已有上下文单独展示。集中清理消息、草稿、workspace 输入和滚动状态，由成功且会话 ID 或 workspace 变化的路径触发。相比无条件清屏，失败和重复打开不会丢用户草稿。用终端内存后端验证状态变化和显示结果，命令和面板入口都调用同一状态同步。
2. **SQL 一次提交。** 现有异步连接开启事务，所有事件读取写入和 revision 更新使用事务引用。事件插入采用冲突不写入后读取校验，避免 PostgreSQL 在重复插入错误后整笔事务不可用。事务由 Rust 所有权控制，错误通过 Result 返回并回滚；提交完成才报告成功。相比单纯包住原有错误重试，这也保留跨 SQL 后端的安全重试。
3. **校正由会话保存。** 在现有快照对象顶层加可选 `context_token_bias`，保存调用显式传入当前值；载入单独校验并以缺省零兼容旧记录。模型 Prompt 仍拥有协议消息，不承担用量字段。恢复只使用 restore 和原始展示事件，不再 commit 未完成轮次。压缩成功必须先清零校正再发布检查点。
4. **授权按快照 ID 同步。** 授权门提供当前待回复 ID，GUI 快照带该 ID；前端仅保留与快照有效 ID 一致的弹窗。匹配操作的完成快照清除 pending/live，queued 清除旧授权，旧回复仍按 ID 清除。无请求 ID 的重连快照保留可能已经入队的新操作，避免吞掉其后续流式事件；保留既有请求 ID 过滤以防旧快照清除新授权，不引入新的会话订阅框架。
5. **路径及空结果。** 路径解析继续用本机 Path 的绝对路径判断和显式 workspace 拼接，识别成对包装引号；不搜索其他目录、不进行存在性回退，以免读取同名错误文件。读取先验证普通文件，拒绝 NUL 二进制片段，空正文元信息附带 `empty` 和说明，错误保留统一分类与建议，预算仍包含完整元信息。用注入授权的双协议 Agent 回归验证成功、空文件及文件错误；非交互模拟服务验证失败说明进入后续 HTTP 请求，沿用授权失败关闭。
6. **验收环境隔离。** 原有可执行文件夹具使用符号链接，`current_exe` 回到 target 后会加载仓库 `.env`，导致默认数据库检查失效；缺依赖夹具清空环境也会丢失实际工具脚本。测试可执行文件改用 target 外、源码同文件系统目录中的硬链接，不复制大二进制；命令夹具隔离 PATH 和启动钩子但保留脚本/参数。不改变运行时的配置选择或用户配置文件。

教程中隐式 cwd 和对象状态分别映射到借用的 workspace 路径与会话拥有的状态；异步模型流、blocking 文件任务和配置读取继续沿用现有实现，std 与现有依赖足够，无新 crate。

## Risks / Trade-offs

- [未确认的工具副作用] → 仅恢复检查点与中断提示，不自动执行。
- [旧快照缺字段] → 缺省零；新增字段无数据库迁移，非法数值拒绝恢复。
- [文件路径歧义] → 严格使用本机语义和当前 workspace；不猜测跨平台绝对路径或同名文件。
- [跨数据库验证范围] → 本地 SQLite 验证事务回滚及幂等；未配置其他数据库时记录未实测范围。

## Migration Plan

无需表结构或配置迁移，旧会话可直接打开；新增 GUI 快照字段随同前后端构建发布。回退旧二进制时新增快照字段由既有反序列化忽略。
