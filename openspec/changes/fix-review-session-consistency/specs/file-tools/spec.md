## Purpose

文件工具让模型在用户授权后定位、读取和修改当前工作目录中的文本，并通过可解释的目标路径和读取结果区分真实正文、空文件及失败，防止把未读取到内容误解为已经检查过目标文件。

## ADDED Requirements

### Requirement: Workspace 文件路径解释

文件工具 MUST 将相对路径相对当前 workspace 解析，直接使用本机绝对路径，并支持家目录简写及成对引号包装的路径；切换及恢复会话后 MUST 使用目标会话的 workspace。路径无效或不存在 MUST 返回实际目标和失败原因，不尝试使用其他 workspace 中的同名文件替代。

#### Scenario: 同名相对路径

- **WHEN** 两个 workspace 都有同名相对文件，用户切换或恢复其中一个并请求读取
- **THEN** 返回目标 workspace 的文件正文，绝对路径仍指向显式指定的目标

#### Scenario: 包装引号

- **WHEN** 路径被成对单引号或双引号包装且目录名含空格
- **THEN** 包装引号被识别，目录名中的空格和其余字面字符保持原义

### Requirement: 无正文的明确反馈

读取工具 MUST 向模型明确区分成功的空文件、目标不是普通文件、文件不存在、无法访问、无效文本及范围错误；成功空文件 MUST 明确说明没有正文，失败 MUST 返回错误类别、目标路径及可执行的恢复建议，不把失败表示成空文件。

#### Scenario: 空文件及失败

- **WHEN** 模型分别读取空文件、不存在的路径、目录或非文本内容
- **THEN** 空文件成功返回明确空内容说明；其余情况返回明确失败和恢复建议，模型可见这些结果
