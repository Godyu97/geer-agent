## ADDED Requirements

### Requirement: 流式用量增量

终端 MUST 将流式输出的字符估算仅作为当前新增输出计入本轮和累计用量，不额外加上已有上下文；用量报告到达后 MUST 清除本次输出估算，使用已报告的输入及输出用量。

#### Scenario: 已有上下文时开始输出

- **WHEN** 已有上下文为 1000 tokens、本轮已报告 10、累计已报告 100，收到 5 个未报告的输出字符
- **THEN** 本轮显示约 13、累计显示约 103，上下文仍为 1000，不额外累计上下文

### Requirement: 终端会话切换显示隔离

终端 MUST 在成功新建、打开其他会话、切换到其他 workspace 后清除旧消息、聊天草稿、工作目录输入及滚动位置，并允许显示一条操作结果提示。打开当前会话、设置相同 workspace 或操作失败 MUST 保留原消息与草稿。

#### Scenario: 新建及恢复其他会话

- **WHEN** 用户新建会话或通过命令、会话面板打开其他会话
- **THEN** 旧 transcript 消失，提示与状态指向目标会话，不把旧对话显示为新会话的一部分

#### Scenario: Workspace 切换失败或无变化

- **WHEN** 目标目录不可访问，或目标仍是当前 workspace
- **THEN** 旧消息与草稿保留，反馈明确说明错误或无变化
