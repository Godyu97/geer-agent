## ADDED Requirements

### Requirement: 桌面授权同步与过期清理

桌面界面 MUST 在收到有效快照时根据当前有效授权 ID 清理过期弹窗，并在新操作入队时清除旧授权；重连后不得因已经取消的授权阻止提交。迟到的旧操作快照或旧授权回复 MUST 不清除新操作中的有效授权。

#### Scenario: 重连取消授权

- **WHEN** 连接恢复且后端已经取消旧授权，新的快照没有有效授权
- **THEN** 前端清除旧弹窗，空闲时允许再次提交

#### Scenario: 迟到回复和快照

- **WHEN** 新授权出现后，旧授权回复返回或旧操作快照到达
- **THEN** 新授权保留，旧 ID 不能清除或允许新授权
