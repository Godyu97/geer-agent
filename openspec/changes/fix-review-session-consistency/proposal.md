# Proposal

## Why

Review 发现流式用量、终端切换、检查点保存恢复和桌面授权的边界状态不一致，可能误导用户或破坏后续恢复。文件工具虽已传入会话 workspace，仍需让路径格式及无正文的反馈可验证、可恢复。

## What Changes

- 流式本轮与累计只增加新增输出的估算，避免重复累计上下文。
- 成功新建、打开其他会话或切换 workspace 后，终端清除旧消息与草稿；失败和无变化保留原状态。
- SQL 检查点与关联增量一起成功或一起失败，仍支持相同事件的安全重试。
- 磁盘恢复保留未完成轮次及上下文用量校正，兼容没有校正字段的旧记录。
- 桌面快照和重连清理过期授权，继续按授权 ID 隔离迟到回复。
- 文件工具以当前 workspace 解释相对路径，兼容成对引号包装的路径；读取明确区分空文件、非文件和失败，向模型提供原因与建议。

## Capabilities

### New Capabilities

无新增教程能力；沿用已经实现或正在规划的能力 ID。

### Modified Capabilities

- `tui`：流式显示及会话切换的状态隔离。
- `session-persistence`：原子检查点和保真恢复。
- `gui`：快照同步时授权有效性。
- `file-tools`：沿用既有变更中的能力路径，强化 workspace 路径及无正文反馈。

## Impact

涉及现有终端界面、SQL DAO、会话运行态、Agent 检查点调用、桌面事件模型及文件工具。仅为现有 Day4、Day6、Day7 能力修复，不引入新依赖、不改变数据库表结构。

## Non-goals

不实现 Day8 权限沙箱、不改变绝对路径和家目录支持、不改变本会话工具授权语义、不重放中断工具、不重写协议或 UI 架构。
