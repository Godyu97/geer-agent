# Spec Delta

## Purpose

让模型通过明确的文本文件工具读取项目内容、创建或覆盖文件，以及对现有文件进行可预测的精确修改。工具支持相对和绝对路径，并在本次会话首次使用各工具时征求用户授权，使文件操作及失败原因都能回到对话循环。

## ADDED Requirements

### Requirement: 文本读取

系统 MUST 接受路径及可选的起始行和行数，读取 UTF-8 文本；起始行从 1 计数。单次结果 MUST 限制在 2000 行和 50 KiB 内，未读完时提示续读位置，无法读取或参数无效时返回明确错误。

#### Scenario: 分段读取

- **WHEN** 模型按路径读取超过单次限制的文本文件
- **THEN** 系统返回当前片段并提示下一次读取的起始行

#### Scenario: 非文本或无效范围

- **WHEN** 路径不是有效 UTF-8 文本，或起始行超出文件范围
- **THEN** 系统返回错误，不把无效内容交给模型

### Requirement: 创建与覆盖

系统 MUST 接受路径和文本内容，在授权后创建缺失的父目录和文件，或覆盖已有文件；失败时 MUST 返回原因。

#### Scenario: 创建新文件

- **WHEN** 模型提供新文件路径和内容，且用户已授权 `write`
- **THEN** 系统创建文件及所需父目录，返回完成结果

### Requirement: 精确编辑

系统 MUST 接受文件路径和一组旧文本/新文本替换；每段旧文本 MUST 在原文件中唯一匹配且各替换区间互不重叠。任一匹配无效时 MUST 保持文件不变并返回原因。

#### Scenario: 多处互不重叠的编辑

- **WHEN** 所有旧文本在原文件中各匹配一次且互不重叠
- **THEN** 系统一次写入所有替换后的内容并返回结果

#### Scenario: 缺失、重复或重叠匹配

- **WHEN** 任一旧文本缺失、出现多次或与另一替换重叠
- **THEN** 系统拒绝整次编辑，文件内容保持原样

### Requirement: 文件工具授权与路径

系统 MUST 对 `read`、`write`、`edit` 分别在本次会话首次使用时展示目标路径并取得明确授权；授权后允许使用相对启动目录的路径或本机绝对路径。拒绝或 `/reset` 后 MUST 不沿用授权。

#### Scenario: 首次授权与重置

- **WHEN** 用户首次允许某文件工具，随后再次使用，再输入 `/reset` 后再次使用
- **THEN** 第二次调用复用授权，重置后的调用重新询问
