# Proposal

## Why

Day 3 的 Bash 可间接读写文件，但常用文件操作需要明确参数和可检查的编辑语义。按 Day 4 的能力节奏，将 pi 的核心 `read/write/edit` 行为接到现有工具循环。

## What Changes

- 模型可读取 UTF-8 文件，按行续读，过长内容会截断并提示续读位置。
- 模型可创建或覆盖文件，也可对现有文件做一组精确、不重叠的文本替换。
- 三种文件工具分别在会话首次使用时询问授权；路径可位于本机任意位置，`/reset` 清除授权。

## Capabilities

### New Capabilities

- `file-tools`：文本文件读取、写入、精确编辑及授权行为。

### Modified Capabilities

无。

## Non-goals

- 不支持图片或二进制文件，不照搬 pi 的图像、模糊匹配和扩展系统。
- 不新增仓库路径隔离或持久权限配置。

## Impact

扩展共享工具清单与执行入口，复用已有调用循环和会话授权；不改变模型接口选择或运行入口。
