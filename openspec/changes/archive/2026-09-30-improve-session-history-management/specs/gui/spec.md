# Spec Delta

## Purpose

桌面界面让用户在本地窗口中使用既有对话和会话能力，并能通过可读标题、明确的多选状态和一次删除确认整理历史，同时在失败和当前会话变化时给出准确反馈。

## ADDED Requirements

### Requirement: 桌面会话批量管理

GUI MUST 在会话侧栏提供管理模式、复选框、全选/取消全选、已选数量及删除所选。管理模式点击条目 MUST 只改变选择，正常模式点击 MUST 打开对应会话。选择 MUST 按 UUID 保存，全选 MUST 只包含当前加载列表；切换范围、workspace、打开会话或退出管理 MUST 清空选择。

#### Scenario: 范围切换
- **WHEN** 用户勾选当前 workspace 的会话后切换到全部范围
- **THEN** 旧选择被清空，新的全选仅包含全部范围当前已加载的条目

#### Scenario: 批量删除与失败
- **WHEN** 用户确认删除所选会话且部分删除失败
- **THEN** 列表刷新，成功项消失，失败项保留选择并显示原因，用户可重试失败或残留清理项

### Requirement: 桌面删除确认与忙碌状态

GUI MUST 在删除前显示一次默认取消的确认，冻结目标 UUID 集合并显示标题、数量、完整 UUID 和删除影响。模型调用、授权或关闭期间 MUST 禁止删除。取消删除和删除其他会话 MUST 保留聊天草稿，当前会话删除成功 MUST 显示新的空会话。

#### Scenario: 取消和忙碌
- **WHEN** 用户取消删除，或操作在模型运行期间触发
- **THEN** 不删除会话，现有消息和草稿保持不变
