# Spec Delta

## Purpose

桌面 GUI 让用户在 Linux Wayland 与 Windows 11 的窗口中使用现有 Agent 对话、会话和工具能力，同时保留终端入口。界面呈现流式回答、完整聊天记录与用量，并在授权、配置错误和退出保存时给出明确反馈。

## ADDED Requirements

### Requirement: 可选窗口入口

系统 MUST 允许包含 GUI 能力的程序通过环境配置选择窗口界面，默认交互终端及管道行为 MUST 保持原样。用户明确选择 GUI 而当前构建不含该能力时 MUST 明确报错，不得悄悄切换界面。

#### Scenario: 从终端启动 GUI
- **WHEN** 用户在当前工作目录启动包含 GUI 能力的程序并配置使用 GUI
- **THEN** 系统打开窗口，沿用当前工作目录与已有模型配置

#### Scenario: 未编入 GUI
- **WHEN** 用户要求 GUI 而程序不含 GUI 能力
- **THEN** 系统说明该构建不可用 GUI 并给出构建提示

#### Scenario: 默认终端兼容
- **WHEN** 用户未指定界面，分别在交互终端和管道中启动
- **THEN** 系统分别使用原有 TUI 与文本 REPL

### Requirement: 桌面对话与会话历史

系统 MUST 在窗口内提供输入、流式回复、已有命令、会话列表与切换。窗口 MUST 展示当前会话完整的已记录聊天历史；模型上下文压缩不得删去已记录的展示历史。切换会话后不得把另一会话的消息留在当前消息区。

#### Scenario: 流式回复和工具进度
- **WHEN** 用户提交输入并收到模型增量或工具进度
- **THEN** 窗口按顺序展示可读内容，并阻止同一时间再次提交或切换会话

#### Scenario: 压缩后恢复旧会话
- **WHEN** 用户打开曾经压缩且成功保存的会话
- **THEN** 窗口显示该会话已记录的完整聊天历史，后续模型请求仍使用正确的可恢复上下文

#### Scenario: 存储关闭与保存失败
- **WHEN** 会话存储关闭或最近写入失败
- **THEN** 进程内切换仍保留对应历史，跨进程只呈现成功发布的记录，不把未保存内容标为已持久化

### Requirement: 桌面输入与状态

系统 MUST 支持中文输入法组合输入、粘贴、历史滚动、代码块复制和安全呈现模型 Markdown。窗口 MUST 显示当前模型、会话、上下文估算及本轮和累计 token 用量，区分临时估算、真实用量与接口缺失的用量。

#### Scenario: 输入法与发送
- **WHEN** 用户正在通过中文输入法选择候选词并按回车
- **THEN** 候选词被确认，消息不提前发送；组合完成后的发送操作正常工作

#### Scenario: 不可信回答
- **WHEN** 模型回答包含 HTML、脚本或外部资源标记
- **THEN** 窗口将其作为不可信内容安全呈现，不执行脚本或自动读取外部资源

#### Scenario: 流式用量
- **WHEN** 模型回答完成且接口报告或不报告用量
- **THEN** 报告值替换临时估算；无报告时显示用量不完整，不把字符估算当作真实用量

### Requirement: 工具授权与关闭保存

系统 MUST 在窗口内显示工具授权范围，并沿用当前会话首次授权规则；未明确允许的工具调用 MUST 被拒绝。关闭窗口时 MUST 尝试保存待写会话；保存失败 MUST 展示未保存会话及重试入口。

#### Scenario: 拒绝授权
- **WHEN** 用户拒绝授权、关闭窗口或授权窗口失去连接
- **THEN** 待授权工具不执行，等待被解除

#### Scenario: 会话切换
- **WHEN** 用户切换会话或重置会话
- **THEN** 原会话中的工具授权不用于新会话

#### Scenario: 忙碌时退出
- **WHEN** 用户在模型轮次执行中请求关闭
- **THEN** 窗口显示等待状态，本轮结束后保存；保存失败时显示未保存会话并允许重试、返回或明确退出
