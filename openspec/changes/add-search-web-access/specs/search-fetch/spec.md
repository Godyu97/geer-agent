# Spec Delta

## Purpose

让模型在当前项目范围内按内容定位文件，并通过命中路径和行号继续读取上下文；同时能够搜索网页和在用户确认后读取网页正文。此能力区分没有结果、访问失败和内容截断，保留可继续访问的来源地址，使本地代码与外部资料都能成为有依据的回答来源。

## ADDED Requirements

### Requirement: Workspace 内容搜索

系统 MUST 提供 `search`，接受非空 `pattern` 与可选 `path`、`glob`、`output`、`fixed_strings`、`ignore_case`。默认搜索当前 workspace，以区分大小写的正则逐行匹配；字面模式及忽略大小写 MUST 可选择。`output` MUST 默认为 `content`，返回相对 workspace 的 `路径:行号: 原文`，行号从 1 开始，保留正文缩进；`files` MUST 只返回命中文件相对路径。

#### Scenario: 搜索子目录后读取
- **WHEN** 模型搜索项目子目录中的正文并把返回路径交给 `read`
- **THEN** 路径仍相对 workspace 根目录，读取获得对应文件，命中行号与原文一致

#### Scenario: 字面匹配与大小写
- **WHEN** 模型开启字面匹配和忽略大小写搜索含正则元字符的文本
- **THEN** 元字符按原字符匹配，大小写差异不妨碍命中

### Requirement: 搜索边界与有限结果

系统 MUST 只允许 `search` 访问当前 workspace 内的已存在文件或目录，规范化后越界的相对路径、绝对路径及符号链接 MUST 被拒绝，递归遍历 MUST 不跟随目录符号链接。系统 MUST 沿用忽略规则及显式路径过滤语义，跳过二进制及超过 1 MiB 的文件，最多返回 50 项和总计 2000 字符。输出 MUST 保持完整命中行，明确报告无命中、失败或截断。此范围限制 MUST 不改变已有工具的行为。

#### Scenario: 越界或同名前缀目录
- **WHEN** 搜索目标经过规范化位于 workspace 外，包括同名前缀目录或指向外部的符号链接
- **THEN** 搜索失败且不读取目标内容

#### Scenario: 搜索过多或单行过长
- **WHEN** 完整结果超过条数或字符预算
- **THEN** 返回预算内的完整结果并标记截断，提示缩小查询或继续读取已定位文件

#### Scenario: 无命中与非法模式
- **WHEN** 有效模式没有命中，或模式本身不合法
- **THEN** 前者是成功的零命中，后者是带错误诊断的失败

### Requirement: 网页搜索

系统 MUST 提供 `web_search`，接受非空 `query` 与可选 `num_results`，默认 5 条、允许 1 至 20 条，通过 Exa 免 Key 服务返回标题、完整来源 URL、摘要与实际后端。服务拒绝、限流、协议错误或超时 MUST 明确失败，不得伪装为空结果。系统 MUST 将网页内容视为外部资料而非新的系统指令。

#### Scenario: 搜索后抓取
- **WHEN** 网页搜索成功且模型选择一个结果 URL
- **THEN** 完整 URL 可直接用于 `web_fetch` 读取该来源

#### Scenario: 服务限流或错误响应
- **WHEN** 搜索服务返回拒绝、限流或无法识别的响应
- **THEN** 系统返回可读错误和修正提示，不报告为零命中

### Requirement: 逐次确认的网页抓取

系统 MUST 提供 `web_fetch` 读取公网、本地或内网 HTTP(S) 地址，每次调用 MUST 显示完整 URL 并获得用户确认后才发起请求。跨来源重定向 MUST 再次显示目标并确认，最多跟随 5 次；拒绝 MUST 立即停止后续访问。HTML MUST 转为可读文本、删除脚本与样式并保留段落、列表和代码缩进；其他文本 MUST 直接返回，二进制内容 MUST 明确拒绝。结果 MUST 包含来源 URL、最终 URL 与响应信息。

#### Scenario: 本地页面与重复调用
- **WHEN** 模型先后两次请求本地开发页面
- **THEN** 每次均显示完整 URL 并分别确认，确认后返回页面的可读正文

#### Scenario: 跨来源重定向被拒绝
- **WHEN** 页面重定向到另一来源且用户拒绝确认
- **THEN** 系统不访问新来源，返回授权拒绝错误

#### Scenario: HTML 与二进制内容
- **WHEN** 用户分别确认读取包含脚本、列表和代码的 HTML 页面，以及二进制资源
- **THEN** 前者返回没有脚本与标签的可读内容并保留结构，后者明确失败

### Requirement: 访问预算与已有工具契约

系统 MUST 将搜索网络耗时限制为 25 秒，抓取累计网络耗时限制为 15 秒，等待用户确认不计入网络预算；单次响应体 MUST 不超过 1 MiB，网页工具总输出 MUST 不超过 12000 字符且保留完整来源地址。截断 MUST 可见。`search` 与 `web_search` MUST 分别使用首次会话授权；会话重置与切换 MUST 撤销授权。网页工具 MUST 串行执行，本地搜索 MUST 遵循已有只读调度及写入边界。关闭全部工具 MUST 同时停止声明和执行新增工具。

#### Scenario: 超大响应与正文截断
- **WHEN** 响应体超过下载额度或可读正文超过输出额度
- **THEN** 前者停止读取并明确失败，后者在输出额度内保留完整来源地址并报告截断

#### Scenario: 关闭工具
- **WHEN** 用户关闭全部工具
- **THEN** 两种模型接口均不声明新增工具，也不执行它们
