# Spec Delta

## Purpose

本能力提供终端中的持续聊天入口，并负责取得模型请求所需的配置。配置既可由运行时环境提供，也可在用户选择单文件分发方式时随程序携带，确保复制产物后仍能启动交互，同时允许用户通过运行时配置覆盖构建时的默认值。

## ADDED Requirements

### Requirement: 可选内嵌配置

系统 MUST 提供可选构建模式，将构建时的配置内容嵌入产物。启用该模式时，系统 MUST 允许产物在没有外部配置文件和进程配置的目录中使用内嵌值；进程环境变量 MUST 覆盖运行目录的文件值，运行目录的文件值 MUST 覆盖内嵌值。未启用时，系统 MUST 保持现有配置读取行为。启用内嵌模式而构建时无配置文件，构建 MUST 明确失败。

#### Scenario: 单文件运行

- **WHEN** 用户启用内嵌构建模式，构建时提供有效配置，并将产物移至没有配置文件的目录运行
- **THEN** 程序使用内嵌配置进入 REPL

#### Scenario: 配置覆盖顺序

- **WHEN** 进程环境、运行目录的配置文件和内嵌配置对同一项目提供不同值
- **THEN** 程序使用进程环境中的值；进程环境缺失时使用运行目录文件中的值

#### Scenario: 普通构建

- **WHEN** 用户未启用内嵌构建模式
- **THEN** 程序只从运行目录的配置文件和进程环境读取配置

#### Scenario: 内嵌源缺失

- **WHEN** 用户启用内嵌构建模式但构建时没有配置文件
- **THEN** 构建失败，并指出缺少构建输入
