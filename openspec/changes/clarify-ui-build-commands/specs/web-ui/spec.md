## Purpose

浏览器界面让仓库所有者在本机和局域网设备使用已有 Agent 能力，通过访问口令保护会话和工具入口，在多个浏览器之间同步当前会话、实时回答与授权状态，并以与桌面一致的界面完成聊天和会话管理。

## ADDED Requirements

### Requirement: 通用程序按环境选择界面

包含桌面和浏览器能力的通用程序 MUST 每次启动时根据 GEER_AGENT_UI 选择 gui、web、tui 或 repl，进程环境 MUST 优先于配置文件。构建和发布通用程序 MUST 不固定启动界面。未显式选择或设为 auto 时 MUST 保留交互终端进入 TUI、管道输入输出进入 REPL 的行为。TUI 没有交互终端或精简程序不包含所选能力时 MUST 明确失败。

#### Scenario: 同一程序切换界面

- **WHEN** 用户分别设置 GEER_AGENT_UI 为 gui、web、tui 或 repl 后启动同一通用程序，配置和运行环境满足对应要求
- **THEN** 每次进入指定界面，无需重新构建

#### Scenario: 进程设置覆盖配置文件

- **WHEN** 配置文件选择 gui，用户启动时将 GEER_AGENT_UI 设置为 repl
- **THEN** 程序进入 REPL，不启动桌面窗口

#### Scenario: 自动模式与能力不足

- **WHEN** 用户未选择界面、选择 TUI 但没有终端，或选择精简程序未包含的界面
- **THEN** 自动模式按终端状态选择 TUI 或 REPL，无法满足显式选择时报告具体错误

### Requirement: 浏览器默认监听端口

系统 MUST 在用户未设置 GEER_AGENT_WEB_PORT 时监听 0.0.0.0:8827；用户显式设置该变量时 MUST 使用其指定的有效端口，范围为 1 到 65535。端口配置非法或监听端口被占用时 MUST 明确失败，不能静默换端口。

#### Scenario: 未设置端口

- **WHEN** 用户启动浏览器模式，未设置 GEER_AGENT_WEB_PORT，其他必需配置有效且端口可用
- **THEN** 服务在 0.0.0.0:8827 提供页面，启动输出显示使用 8827 的访问地址

#### Scenario: 显式覆盖默认端口

- **WHEN** 用户将 GEER_AGENT_WEB_PORT 设置为 8828 后启动浏览器模式，其他必需配置有效且端口可用
- **THEN** 服务在 0.0.0.0:8828 提供页面，启动输出显示实际配置的端口

#### Scenario: 端口配置或监听失败

- **WHEN** 用户配置的端口为空、零、超出范围或不是整数，或所选监听端口已被占用
- **THEN** 程序明确报错退出，不自动改用其他端口
