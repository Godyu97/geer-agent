# Spec Delta

## Purpose

让模型在用户知情授权后调用本机 Bash，检查目录、运行测试和读取命令结果。命令输出、退出状态和失败原因会进入工具结果，执行时间与回传长度受到限制，避免一次命令让对话长时间停住或淹没上下文。

## ADDED Requirements

### Requirement: 会话内授权

系统 MUST 在本次 REPL 会话首次使用 `bash` 时展示完整命令及授权范围并询问用户；只有明确回答 `y` 或 `yes` 才 MUST 执行，并允许该工具在同一会话后续调用中复用授权。拒绝、无交互输入或 `/reset` 后 MUST 不沿用授权。

#### Scenario: 首次允许

- **WHEN** 模型首次请求 `bash` 且用户回答 `y`
- **THEN** 系统执行该命令，并在同一会话后续 Bash 调用中复用授权

#### Scenario: 拒绝执行

- **WHEN** 用户拒绝首次授权或无法交互确认
- **THEN** 命令不执行，系统向模型返回拒绝结果

#### Scenario: 重置会话

- **WHEN** 用户输入 `/reset` 后模型再次请求 Bash
- **THEN** 系统重新询问授权

### Requirement: 受限命令执行

系统 MUST 在启动目录执行命令，10 秒后停止超时命令，返回退出状态及标准输出和错误输出，并将回传文本限制在 2000 字符内。

#### Scenario: 命令成功或失败

- **WHEN** 已授权的命令正常结束
- **THEN** 系统向模型返回输出和退出状态

#### Scenario: 命令超时或输出过长

- **WHEN** 命令超过 10 秒或输出超过 2000 字符
- **THEN** 系统终止超时命令或截断结果，并明确标示原因
