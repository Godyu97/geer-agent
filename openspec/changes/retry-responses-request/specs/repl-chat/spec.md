# Spec Delta

## ADDED Requirements

### Requirement: Responses 请求失败重试

系统 MUST 在 Responses 请求尚未显示模型正文就失败时，最多自动重试五次。每次重试前，系统 MUST 在 Ai 输出区显示按顺序编号的 `retry n/5...`。任一次完整成功后，系统 MUST 保存该轮对话；所有尝试均失败时，系统 MUST 显示最终错误、不保存失败轮次，并继续等待输入。若模型正文已经显示，随后发生的失败 MUST 直接报错，不得自动重试。

#### Scenario: 短暂失败后成功

- **WHEN** 初次请求失败且重试期间某次请求成功
- **THEN** Ai 输出区显示此前各次重试编号，回答继续流式显示，完整成功后保存该轮对话

#### Scenario: 五次重试仍失败

- **WHEN** 初次请求及其后的五次重试均在输出正文前失败
- **THEN** Ai 输出区依次显示 `retry 1/5...` 至 `retry 5/5...`，随后显示最终错误，不保存失败轮次并继续等待输入

#### Scenario: 部分正文后失败

- **WHEN** Responses 已显示部分正文后流读取失败
- **THEN** 系统直接显示错误，不显示重试编号，不保存失败轮次并继续等待输入
