# Design

## Context

动机见 proposal.md。现有 Rust `ui/app` 在专属线程持有 Agent，`EventHub` 拒绝第二个运行命令；Tauri 和 Web 只桥接拥有所有权的事件。模型没有在浏览器主线程执行。前端 `App` 对所有操作复用 `disabled`，记忆面板把同一标志用于关闭；每个 delta 都触发整页更新与历史 Markdown 解析。

主 `gui` spec 要求运行时禁止再次提交、切换与删除；本次只释放本地编辑和阅读，保持这些要求。`add-web-ui` 已实施但未归档，代码与测试确认 Web 使用同一 App，故共用交互要求放入已有 `gui` 能力，不另造近义能力。

### 页面与交互梳理

| 区域 | 用户任务 | 当前执行边界与本轮处理 |
| --- | --- | --- |
| 左侧工作区与会话 | 新建、打开、范围选择、批量管理 | 新建/打开/删除经串行命令；范围与勾选只更新本地状态，本轮解除无关的忙碌限制 |
| 中间聊天区 | 阅读、Markdown、复制、展开工具 | 完成历史按轮呈现；本轮复用历史渲染、合并活动正文、显式返回最新 |
| 输入区 | 编辑、发送、查看运行状态 | 草稿属于本端会话；发送需要空闲；本轮允许思考期间编辑并保护迟到回包 |
| 顶栏与右侧状态 | 记忆、压缩、保存、模型/用量查询 | 压缩/保存仍串行；状态只读；窄屏通过抽屉访问侧栏 |
| 记忆/授权/删除弹层 | 管理数据与确认操作 | 写入仍互斥；本轮修复记忆面板退出被工作状态锁住，授权与删除仍显式确认 |

| 操作 | 空闲已连接 | 模型运行 | 断线已保留快照 |
| --- | --- | --- | --- |
| 阅读/复制、展开工具、查看状态 | 可用 | 可用 | 可用 |
| 会话范围与勾选 | 可用 | 可用 | 可用 |
| 编辑聊天草稿 | 可用 | 可用，不排队 | 保留内容，等待重连 |
| 记忆搜索与关闭面板 | 可用 | 可用 | 可用 |
| 发送、切换/删除会话、写记忆、压缩/保存 | 可用（遵守确认） | 等待当前操作结束 | 等待重新同步 |

授权、删除确认和关闭流程仍具有各自的交互边界，不能由“本地可编辑”绕过。

## Goals / Non-Goals

**Goals:** 将会话写操作互斥与本地浏览/草稿状态分开，控制流式渲染成本，确保弹层能退出、草稿不丢。

**Non-Goals:** 不给 Rust Agent 增加共享可变所有权或取消 future，不更改服务器命令与事件，不新增 crate、前端依赖、环境配置或持久化迁移。

## Decisions

1. **交互权限分层。** 保留发送及写操作的互斥判断；独立的本地控件限制只关注初始化、关闭和确认弹窗。聊天草稿在运行中可编辑，断线保留原有保护；会话范围、管理和复选框在模型运行时可用。记忆面板的关闭与 Escape 不依赖工作线程状态，Escape 先取消编辑再关闭。不要直接移除全局保护，否则会产生跨会话竞争与删除误操作。
2. **异步草稿保护。** 提交时记住会话、草稿内容与编辑版本；宿主确认后仅清除未继续编辑的同一草稿。失败保持内容并显示错误。新编辑不排队、不自动发送。保留 IME 与 Shift+Enter 规则，运行中 Enter 不吞掉下一条消息。
3. **有序合并输出。** 在共用连接处以约 40ms 的短窗口合并同一请求的连续正文，其他事件立即刷新已缓冲正文再按顺序分发；断开清理定时器。最终快照、授权、工具和新请求不等待计时器。选择小规模缓冲而非 Worker/虚拟列表，以免引入第二套协议或破坏按轮折叠。稳定复制回调与历史轮次 memo 避免重新解析旧 Markdown；活动正文用延迟值让输入优先。
4. **进度与阅读。** 输入区的状态条从真实事件派生等待、接收、工具、授权、连接与收尾状态，只说明可观察状态，不推断隐藏 think 内容或百分比。保持已有跟随底部规则，增加返回最新消息按钮；用户阅读上方时不自动滚动。
5. **视觉。** 保持三栏布局和 Mocha 品牌，统一 8–14px 圆角、控件边框、主次按钮、选中和焦点反馈；改善输入区与消息留白。窄屏顶栏允许换行，避免挤压会话标题，保留抽屉。尊重 reduced-motion。

教程中的串行工具循环仍映射到 Rust 工作线程唯一拥有的 Agent，错误经事件显式展示，流式缓冲只是前端呈现节奏；不会影响模型、工具授权、数据库或环境配置。

## Risks / Trade-offs

- [合并增量造成乱序或卸载后回调] → 覆盖多个请求、工具、授权、快照边界与卸载清理，不改 reducer 的请求隔离规则。
- [可编辑输入被迟到确认清空] → 覆盖延迟成功、失败、运行结束与会话变化后的草稿。
- [性能优化不能证明所有机器都不卡] → 回归验证历史不重解析，并用本机模拟连续输出检查桌面/375px 交互；真实模型和原生窗口未实测时如实记录。
- [选择可用被误认为可以切换/删除] → 禁用实际命令并显示运行期间的限制说明，范围按钮使用 pressed 状态。

## Migration Plan

构建共用前端的 GUI/Web 两份产物即可使用，无数据迁移。回退本次前端源码并重新构建恢复旧交互；不触碰会话数据。
