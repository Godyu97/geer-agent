# Spec Delta

## ADDED Requirements

### Requirement: 图形界面运行期间的本地交互

桌面与浏览器界面 MUST 在等待模型或接收回复时允许编辑聊天草稿、切换会话列表范围、勾选会话、阅读与复制历史、查看和关闭记忆面板。再次发送、新建或打开会话、切换工作区、压缩、保存、删除及记忆写入 MUST 继续受操作互斥约束；本地选择不得发起这些操作。

#### Scenario: 思考期间准备下一条消息
- **WHEN** 当前请求尚未返回正文，用户输入下一条草稿、切换范围并勾选会话
- **THEN** 编辑与选择立即可见，发送和删除不可用，按 Enter 不发送或清空草稿，本轮结束后草稿仍需显式发送

#### Scenario: 运行或断线时关闭记忆面板
- **WHEN** 记忆面板已经打开，模型仍在执行或连接中断，用户点击关闭或在无编辑器时按 Escape
- **THEN** 面板关闭并返回聊天，聊天草稿保持不变；编辑器内 Escape 先退出编辑，随后可关闭面板

### Requirement: 图形草稿与异步提交确认

界面 MUST 只在提交成功确认且草稿仍属于该次提交时清空输入；等待确认期间的新编辑、另一会话的草稿和失败提交的草稿 MUST 保留。延迟确认不得自动发送草稿。

#### Scenario: 确认晚于新草稿
- **WHEN** 用户提交后继续修改输入，再收到该次提交成功确认
- **THEN** 新编辑的内容保留，当前请求仍只有一次

#### Scenario: 提交失败
- **WHEN** 提交被拒绝或连接失去确认
- **THEN** 界面显示错误并保留当前草稿，不自动重发

### Requirement: 图形运行反馈与连续阅读

界面 MUST 在输入附近持续显示可观察的等待回复、接收回复、工具调用、待授权或断线状态，并说明何时可发送。流式输出 MUST 保持顺序与完成正文，阅读旧消息时 MUST 不强制滚回底部，并提供显式返回最新消息入口。连续输出时历史阅读、工具展开和输入编辑 MUST 保持可用。

#### Scenario: 等待首段回复
- **WHEN** 模型尚未返回可见正文
- **THEN** 输入附近显示等待回复与可继续编辑草稿的提示，不把等待伪装为内部推理进度

#### Scenario: 阅读旧消息
- **WHEN** 用户向上滚动后继续收到回复
- **THEN** 阅读位置保持，用户点击返回最新消息后恢复跟随输出

#### Scenario: 输出与授权交替
- **WHEN** 连续正文之后收到工具进度、授权或完成事件
- **THEN** 已收到的正文按顺序展示，授权及时可操作，完成后不被迟到的增量重复或覆盖

### Requirement: 图形控件的可辨认状态

桌面与浏览器界面 MUST 沿用 Mocha 色板，以一致的按钮、焦点、留白和对比呈现主要操作、次要操作、危险操作和已选状态。会话范围 MUST 暴露当前选中状态；在 375 像素窄屏下输入、运行提示、面板和主要按钮 MUST 可见可操作，并尊重减少动态效果的系统偏好。

#### Scenario: 键盘与窄屏操作
- **WHEN** 用户通过键盘导航或在窄屏查看正在生成的回答
- **THEN** 焦点清晰，范围选择可辨认，主要控件和提示不溢出视口
