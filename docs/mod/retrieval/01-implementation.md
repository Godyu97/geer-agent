阅读路由：实现问题先检索下面的业务 / 行为标题，再核对代码；验证问题看「验证入口与缺口」。不把未实现需求写成本文件的当前行为。

## 分块与相关度

search 先将长文本按字符边界分为带重叠窗口的片段；查询词项过滤停用词，中文包含相邻汉字词项。随后以 BM25-lite 对片段相关度排序，限制重叠重复并返回原记忆来源，使上层能在 token 预算内提供引用片段。边界参数、空查询和重复片段行为由本文件的单元测试约束。
